# 우짜노 연습앱

어르신이 **진짜 돈·진짜 예매 걱정 없이** 스마트폰 앱 사용을 연습하는 웹앱.
실제 앱과 화면 순서·버튼 위치는 같고, 이름·로고는 자체 브랜드(KW)다.

| 연습 | 가상 브랜드 | 흐름을 따온 앱 | 미션 |
|---|---|---|---|
| 은행 | KW뱅킹 | 주요 은행 공통 | 거래내역 / 손주에게 5만원 / 처음 보내는 계좌(금융사기 확인) |
| 기차표 | KW레일 | 코레일톡 | 서울→대전 예매·결제 / 회원가입(인증번호 문자) / 승차권 확인 |
| 음식 주문 | KW배달 | 배달의민족 | 장바구니 담기 / 주소 설정 / 결제까지 |
| 길찾기 | KW지도 | 네이버 지도 | 두 손가락 확대·축소 / 장소 찾기 / 지하철 경로 |
| 사진 보내기 | KW톡 | 카카오톡 | 사진 1장 / 여러 장 / 친구 찾아 메시지 |
| 노래 모아듣기 | KW뮤직 | 유튜브 | 노래 찾기 / 재생목록 만들기 / 모두 재생 |

연습 비밀번호: 간편·결제 `123456`, 계좌 `1234` (`src/core/config.ts`)

## 실행

```bash
npm install
npm run dev         # PC에서 확인
npm run dev:phone   # 같은 와이파이의 휴대폰에서 확인 (터미널에 뜨는 Network 주소)
npm run build       # dist/ 에 배포용 파일 생성
```

## 배포

`dist/` 폴더를 정적 호스팅(GitHub Pages, Netlify, Vercel 등)에 올리면 된다.
HashRouter + 상대 경로라 하위 경로에 올려도 그대로 동작한다. 배포 주소로 QR 코드를 만들어 안내문에 넣는다.

## 구조

```
src/
  core/            모든 연습 앱이 같이 쓰는 부품
    shell/         '연습용' 띠 · 도움말 · 완료 창
    mission/       미션 상태, emit(이벤트) → 완료 판정, 도움말 계산
    phone/         가짜 문자 알림 · 알림창 · 문자 앱
    flows/         휴대폰 본인인증, 결제
    ui/            상단바 · 시트 · 보안 키패드 · 탭 등
  modules/<앱>/    meta.ts(미션·도움말) · store.ts(상태) · data.ts · screens/
```

**새 연습 앱 추가**: `modules/<이름>/` 에 `meta.ts`·`routes.tsx`를 만들고 `modules/registry.ts`와 `router.tsx`에 한 줄씩 추가.
화면은 미션을 모른다. 행동이 끝나면 `emit('이벤트')`만 부르고, 미션의 `completeOn`이 같으면 완료 창이 뜬다.

## 지켜야 할 것

- 개인정보를 받지 않는다. 연습 상태는 브라우저 탭(sessionStorage)에만 있고 탭을 닫으면 지워진다. 인증 연습의 전화번호는 저장하지 않는다.
- 지도는 OpenStreetMap 타일을 쓴다(저작권 표시 필수, 대량 사용 금지 — 수업 규모는 문제없음). 경로·시각표·요금은 연습용 예시다.
- 지도 '내 위치'를 경로당으로 바꾸려면 `core/config.ts`의 좌표와 `modules/map/data.ts`의 예시 경로를 함께 고친다.
